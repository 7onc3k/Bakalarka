# Bakalarka

Repozitář k bakalářské práci. Pro audit finální odevzdané verze používej
tag `thesis-final`:

<https://github.com/7onc3k/Bakalarka/tree/thesis-final>

## Doplňující Materiály

Na tagu `thesis-final` slouží tento README jako hlavní rozcestník. Samostatný
adresář `experiments/audit-package` se nepoužívá, aby v repozitáři nevznikaly
dva paralelní indexy stejných podkladů.

- `thesis/prace.pdf` obsahuje finální PDF práce.
- `thesis/` obsahuje zdrojové soubory práce a generované obrázky/tabulky.
- `experiments/infra/` obsahuje vstupy experimentu, hodnoticí schémata,
  skripty a operační proceduru.
- `experiments/runs/` obsahuje běhy agenta a naměřené výstupy.
- `experiments/reference/` obsahuje referenční implementaci použitou při
  vyhodnocení.

Pracovní poznámky, konzultace, handoffy, vzorové práce, lokální tooling a
stažené zdroje nejsou součástí čistého release stavu na tagu `thesis-final`.
