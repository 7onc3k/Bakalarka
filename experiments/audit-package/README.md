# Doplňující materiály k případové studii

Tento adresář je čistý vstupní bod pro audit podkladů použitých v bakalářské práci.
Obsahuje pouze index a manifest. Vlastní data zůstávají na původních místech
v repozitáři, aby nevznikaly duplicitní kopie.

Všechny odkazy jsou relativní vůči tomuto repozitáři a mají být čteny ve stavu
označeném tagem `thesis-final`.

- Detailní seznam podkladů: [MANIFEST.md](MANIFEST.md)
- Hlavní experimentální vstupy: [../infra/inputs](../infra/inputs)
- Všechny běhy: [../runs](../runs)

Adresáře běhů obsahují i technické soubory potřebné pro spuštění projektu
(`package.json`, konfigurace testů apod.). Manifest proto odkazuje přímo na
soubory relevantní pro audit metodiky, instrukcí, měření a interpretace.
